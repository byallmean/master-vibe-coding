# Phase 05: UI/UX Design

Responsible Agents: UI/UX Designer, UX Researcher

## Objective

Biến hành trình người dùng thành thiết kế dùng được, nhất quán và tiếp cận được.

## Input

- User Journey
- API Specification

## Execution Steps

Từ version 2.0, giai đoạn này chạy theo chuỗi Design First, không chỉ 5 bước rút gọn ở dưới. Chạy theo thứ tự: D1-product-experience-design.md, D2-visual-design-system.md, D3-prototype-review.md. Mỗi bước cũ dưới đây phải được mở rộng theo file chuỗi tương ứng.

1. Vẽ sitemap và user journey cho luồng chính
2. Xây design token và component tái sử dụng
3. Vẽ wireframe và màn hình chi tiết
4. Làm prototype khi cần kiểm tra luồng phức tạp
5. Kiểm tra responsive và accessibility

## Deliverables

- Design Specification
- Design Tokens
- Component Library
- Screen Specifications

## Quality Gate

Chỉ chuyển giai đoạn khi vượt qua gate tại quality-gates/design-gate.md với trạng thái PASS hoặc CONDITIONAL PASS có biện pháp kiểm soát ghi rõ.

## Failure Handling

Nếu thiết kế không khớp API thì quay lại Phase 04 để điều chỉnh, không tự sửa API trong lúc vẽ giao diện.
