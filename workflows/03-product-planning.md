# Phase 03: Product Planning

Responsible Agents: Product Manager, Technical Project Manager

## Objective

Chọn MVP, chia module, sắp xếp roadmap và milestone có phụ thuộc rõ ràng.

## Input

- PRD
- User Story Backlog

## Execution Steps

1. Chọn MVP theo giá trị sử dụng được nhỏ nhất
2. Chia sản phẩm thành module có ranh giới rõ
3. Chia mỗi module lớn thành story theo templates/STORY.md. Mỗi story tự chứa đủ context: ngữ cảnh, acceptance criteria, file sẽ đọc, file sẽ sửa, lệnh kiểm chứng và output mong đợi. Mỗi story không quá 500 dòng thay đổi code
4. Ưu tiên tính năng theo giá trị và rủi ro
5. Xây roadmap, milestone và release plan
6. Ghi phụ thuộc giữa các module

## Deliverables

- Product Roadmap
- Feature Backlog
- STORY.md cho mỗi story đã chia
- Development Plan
- Release Plan

## Quality Gate

Chỉ chuyển giai đoạn khi vượt qua gate tại quality-gates/requirement-gate.md với trạng thái PASS hoặc CONDITIONAL PASS có biện pháp kiểm soát ghi rõ.

## Failure Handling

Nếu MVP vẫn quá lớn thì cắt bớt tính năng, không kéo dài vô hạn mà vẫn gọi là MVP.
