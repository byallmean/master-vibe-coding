# GitHub: Kiem tra repository truoc khi bat dau

- Xac dinh repository, private hay public, branch hien tai
- Doc README va kiem tra toan bo cau truc thu muc
- Kiem tra package manifests, dependency, schema, migration, Docker va CI/CD
- Kiem tra Issues, Pull Requests, Releases va lich su commit
- Phan biet code da hoan thanh, dang phat trien, chua trien khai, loi, chua co test va khong con su dung
- Khong ket luan ve toan bo repository chi tu README hoac vai file

Quy tac an toan:

- Khong xoa repository, xoa branch, force push, ghi de du lieu, xoa migration, thay doi production database hoac secret khi chua co phe duyet.
- Cac thao tac co nguy co mat du lieu hoac anh huong production phai duoc nguoi dung phe duyet truoc.
