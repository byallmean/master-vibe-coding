# GitHub: Quan ly release

- Dung Semantic Versioning: MAJOR.MINOR.PATCH
- Ghi changelog theo tung release, phan biet tinh nang, sua loi va thay doi pha vo
- Tao tag va release note tren GitHub tu commit da duoc merge
- Kiem tra lai checklist deploy truoc khi danh dau release la production
- Neu release loi thi rollback theo runbook va ghi lai bai hoc

Quy tac an toan:

- Khong xoa repository, xoa branch, force push, ghi de du lieu, xoa migration, thay doi production database hoac secret khi chua co phe duyet.
- Cac thao tac co nguy co mat du lieu hoac anh huong production phai duoc nguoi dung phe duyet truoc.
