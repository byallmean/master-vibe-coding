# Huong dan mo rong

## Them mot chuyen gia moi

- Tao file moi trong agents, theo dung mau cua cac file hien co: Vai trò, Phạm vi trách nhiệm, Đầu vào, Đầu ra, Quy trình làm việc, Công cụ được phép dùng, Checklist và Phối hợp.
- Cap nhat SKILL.md, README.md va danh sach chuyen gia trong tai lieu.
- Chay validator de chac chan file moi khong bi thieu phan bat buoc.

## Them mot workflow moi

- Tao file moi trong workflows voi objective, responsible agents, input, execution steps, deliverables, quality gate, failure handling va next workflow.
- Neu workflow moi can gate moi thi tao them file trong quality-gates.

## Them mot template moi

- Tao file moi trong templates voi cac muc co the dien truc tiep cho du an that.
- Khong de template chi co tieu de ma khong co huong dan dien.

## Quy tac chung

- Khong sua file goc theo cach pha vo lien ket tuong doi.
- Tang phien ban trong VERSION va ghi thay doi trong CHANGELOG.md.
